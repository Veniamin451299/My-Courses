## 🛠️ Как запускать проекты

Каждый проект находится в своей папке и имеет собственный README с инструкциями по запуску. В большинстве случаев используется `docker-compose` для поднятия всех зависимостей.

Пример запуска для любого проекта:

```bash
cd имя-проекта
docker-compose up -d --build
```
