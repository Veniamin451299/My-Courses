Мы подошли к финальной теоретической теме перед стартом пэт-проектов. Посмотри на свой текущий роут `/books/:id`. В нем есть функция `findBookInDB(req.params.id)`.

В реальной разработке **категорически запрещено** писать запросы к базам данных, сложную математику или отправку email-ов прямо внутри роутов. Почему? Если проект вырастет, и тебе нужно будет получить книгу не через HTTP, а, например, через фоновую задачу (Cron) или WebSocket, тебе придется заново переписывать весь код поиска книги.

Поэтому бэкенд разделяют на **слои**. В Express.js стандарт — это разделение на **Роуты (Routes),** **Контроллеры (Controllers)** и **Сервисы (Services)**.

```text
 Клиент (Браузер) ──> [ Слой Роутинга ] (Проверяет URL и Метод)
                              │
                              ▼
                     [ Слой Контроллеров ] (Принимает req, res, выдергивает params/body)
                              │
                              ▼
                     [ Слой Сервисов ] (Чистая бизнес-логика: ищет в БД, считает, меняет)
```

В **NestJS** эта трехслойная архитектура возведена в абсолютный закон. Там папки всегда делятся на `.controller.ts` и `.service.ts`. Давай научимся делать это в Express, чтобы в NestJS ты чувствовал себя как дома.

# Как это выглядит в коде Express.js

Вместо того чтобы писать гигантскую функцию в `app.get()`, мы разделяем код на файлы или объекты.

1. Слой Сервисов (Только работа с данными, не знает ничего про `req` и `res`)
```javascript
// books.service.js
const booksDatabase = [
    { id: '1', title: '1984', author: 'George Orwell' },
    { id: '2', title: 'Brave New World', author: 'Aldous Huxley' }
];

const BooksService = {
    getById(id) {
        // Ищет книгу в массиве (эмуляция БД)
        return booksDatabase.find(book => book.id === id);
    }
};
```

2. Слой Контроллеров (Связующее звено, управляет `req`, `res` и вызовом `next`)
```javascript
// books.controller.js
const BooksController = {
    getBookById(req, res, next) {
        try {
            const book = BooksService.getById(req.params.id); // Дергаем сервис
            
            if (!book) {
                const error = new Error('Книга не найдена');
                error.statusCode = 404;
                return next(error);
            }
            
            res.json(book); // Отвечаем клиенту
        } catch (err) {
            next(err);
        }
    }
};
```

3. Слой Роутов (Только маршруты и мидлвари)
```javascript
// index.js (или app.js)
app.get('/books/:id', BooksController.getBookById);
```
