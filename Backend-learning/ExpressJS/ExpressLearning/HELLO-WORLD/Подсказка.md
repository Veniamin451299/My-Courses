# Точечный совет ментора по синтаксису
Твой вызов .listen(...) в конце цепочки написан лаконично, но в реальных проектах для читаемости принято разделять создание приложения и его запуск:
```javascript
// Настройка роутов
app.get('/home', (req, res) => { ... });

// Запуск сервера отдельной строкой
const PORT = Number(process.argv[2]);
app.listen(PORT, () => {
    console.log(`Сервер успешно запущен на порту ${PORT}`);
});
```
    
Используйте код с осторожностью.Callback-функция внутри app.listen() в реальном продакшене помогает логировать старт сервера, чтобы разработчик сразу видел в консоли, что запуск прошел успешно.
