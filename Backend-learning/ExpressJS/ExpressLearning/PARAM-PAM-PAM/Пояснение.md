 # Params (Параметры пути) — это ИДЕНТИФИКАЦИЯ
 
Они встраиваются прямо в структуру URL (через двоеточие в коде: /:id) и нужны, чтобы указать на конкретный объект в базе данных. Без этого параметра ссылка теряет смысл.

Пример URL: `/users/benjamin или /books/42`. 

Как воспринимает сервер: «Дай мне пользователя с именем Benjamin» или «Найди книгу с ID 42».

Ассоциация: Это как паспортный номер конкретного человека или адрес дома.
