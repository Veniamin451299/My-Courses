# Как эта концепция (SSR) используется в NestJS?
В современном бэкенде чистый Server-Side Rendering (рендеринг HTML на сервере) для сайтов используется реже — сейчас чаще пишут раздельный API (бэкенд отдает JSON, а фронтенд на React/Vue сам строит интерфейс).

Тем не менее, генерация шаблонов на сервере критически важна для:
- Генерации красивых Email-писем (например, подтверждение регистрации, чеки, рассылки). Ты создаешь pug-шаблон письма, подставляешь туда имя пользователя и отправляешь.
- Генерации PDF-отчетов и счетов на лету.

В NestJS для этого тоже используется шаблонизатор Pug (или Handlebars), но настройка переносится в главный файл main.ts через метод app.setViewEngine('pug'), а в контроллерах используется специальный декоратор @Render('index'). Логика сборки шаблона за кулисами остается ровно такой же, какую ты сейчас закрепил!
