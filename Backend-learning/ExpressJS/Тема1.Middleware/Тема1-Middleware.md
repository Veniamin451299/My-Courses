# <span style="color:rgb(255, 0, 0)">Анатомия Middleware</span>

В тренажёре (Expressworks) ты использовал встроенные мидлвари (`express.json()`, `express.static()`). Но в реальной жизни ты будешь писать свои.

<span style="color:rgb(200, 0, 255)">Мидлварь</span> — это <span style="color:rgb(0, 255, 30)">функция</span>, которая имеет доступ к объектам запроса (`req`), ответа (`res`) и к **<span style="color:rgb(0, 255, 30)">следующей</span>** <span style="color:rgb(0, 255, 30)">мидлвари</span> в конвейере Express, которая называется **`next`**.

## Пример кастомной мидлвари-логгера:
```javascript
const requestLogger = (req, res, next) => {
    console.log(`[${new Date().toISOString()}] ${req.method} запрос на ${req.url}`);
    next(); // 🌟 КРИТИЧЕСКИ ВАЖНО: если не вызвать next(), запрос «зависнет» и клиент никогда не получит ответ!
};
```


### Ты можешь подключить её **глобально** для всего сайта:
```javascript
app.use(requestLogger);
```

### Или **локально** только для одного конкретного роута:
```javascript
app.get('/books', requestLogger, (req, res) => { ... });
```

# <span style="color:rgb(255, 255, 0)">Твоё первое практическое задание по теории (Разминка):</span>

Давай закрепим это руками в твоём файле. Создай сервер, в котором:
1. Есть роут `GET /secret`.
2. Напиши кастомную мидлварь `checkAdmin`, которая проверяет: если в Query-параметрах пришло `?role=admin` (то есть `req.query.role === 'admin'`), она вызывает `next()` и пропускает пользователя.
3. Если там любая другая роль или её нет — мидлварь возвращает `403 Forbidden` с текстом "Доступ запрещён" и **НЕ** вызывает `next()`.
4. Подключи эту мидлварь **локально** только к роуту `/secret`.
