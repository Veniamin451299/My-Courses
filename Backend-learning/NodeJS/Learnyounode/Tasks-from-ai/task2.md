Задача 2: Разбор тела POST-запроса (Body Parser)Почему это важно: В Express мы пишем req.body, чтобы получить данные от пользователя. Но под капотом Express собирает этот body по кусочкам из потока данных. Ты должен уметь делать это руками.

Условие:
- Реализуй HTTP-сервер, который принимает только POST-запросы. 
- Клиент присылает в теле запроса (Body) строку в формате JSON (например: {"name": "Benjamin", "role": "developer"}).
- Сервер должен собрать весь этот входящий поток данных в одну строку.
- Распарсить её через JSON.parse().
- Модифицировать объект, добавив туда поле status: "active".
- Вернуть клиенту измененный JSON-объект со статусом 200 и правильным Content-Type.
- Если метод не POST — возвращать 405 Method Not Allowed.

Подсказка ментора: Тело запроса req — это поток (Readable Stream). Тебе нужно будет завести переменную-буфер (строку), подписаться на события req.on('data', chunk => { ... }) и дождаться окончания потока в req.on('end', () => { ... }), где ты и выполнишь отправку ответа.
