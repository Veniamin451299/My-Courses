Задача 3: Безопасная асинхронная работа с файлами. 
Почему это важно: Логирование, загрузка аватарок, чтение конфигураций — бэкенд постоянно работает с диском.
Ошибки здесь не должны ронять сервер.

Условие:
- Реализуй HTTP-сервер, который при GET-запросе по адресу /logs читает файл app.log из текущей папки и возвращает его содержимое клиенту.
- Чтение файла должно быть асинхронным (fs.readFile).
Главное условие: 
- Если файла app.log не существует, сервер не должен падать! Он должен поймать ошибку и красиво ответить клиенту статусом 404 Not Found с текстом "Файл логов не найден".
